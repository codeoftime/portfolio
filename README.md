# Siddhant Pramanik — Portfolio

A gamified, animation-heavy single-page portfolio (Three.js + GSAP + Lenis).

- Open `index.html` in a browser, or enable GitHub Pages (Settings → Pages → `main` / root).
- Put your photos in `images/photo1.jpg`, `images/photo2.jpg`, `images/photo3.jpg` to show them in the Profile section (you can also upload them directly on the page).
